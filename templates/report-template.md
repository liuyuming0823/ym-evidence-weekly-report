# 周报模板

> 复制本文件填充内容。方括号内为来源编号，不可省略；段落为空时保留标题并写明原因。

```
周期：[起止日期]（未指定时写「用户未指定，按最近 7 天」）
汇报对象：[主管 / 团队 / 客户]（未指定时写「默认直属主管」）

## 本周完成
- [成果描述] [记录 N]
- [成果描述] [记录 N]

## 进行中
- [事项与当前进展] [记录 N]

## 阻塞与需支持
- [卡点] 需要的支持：[具体支持] [记录 N]

## 下周计划
- [计划事项]（来自记录 N 的计划表述，或用户确认后的推断）

## 来源索引
| 编号 | 原始记录要点 |
|---|---|
| 记录 1 | ... |

## 需要你确认的推断
- [推断内容] → 依据记录 N，但是否成立请你确认
```

## 填写约束

1. 「本周完成」里每一条都必须带 `[记录 N]`
2. 段落为空时不能删标题，写明「未找到可确认的 XX 项」
3. 推断只能出现在最后一节，不能混进完成段
4. 全文控制在 800 字以内
